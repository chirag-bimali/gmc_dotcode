# Landing Page

## Goal

Introduce Student Hub to prospective universities and students. Communicate the value proposition clearly and drive sign-up interest.

This is the public-facing marketing page before login.

---

# User

Unauthenticated visitors (university decision-makers, curious students)

---

# Route

/

---

# Layout

Public layout (no sidebar, no authenticated nav).

Contains:

- Public Navbar
- Hero Section
- Features Section
- How It Works
- Footer

---

# Page Sections

## Public Navbar

Contains:

- Logo (left)
- Navigation Links: Features, How It Works
- Login Button (right)

Sticky on scroll.

---

## Hero Section

Contains:

- Headline
- Subheadline
- CTA Button
- Hero Illustration or abstract graphic

Example:

Headline: Your Campus Community, Connected.

Subheadline: A verified platform for students to discover clubs, join communities, and never miss an event.

CTA: Get Started

---

## Features Section

Grid of 3–4 feature cards.

Each card contains:

- Icon
- Title
- Short Description

Features:

- Verified Students: Every student is invited by their university.
- Discover Clubs: Browse and join communities that match your interests.
- Campus Events: Never miss what's happening on campus.
- University Managed: Admins have full control over their platform.

---

## How It Works

3 steps, horizontal on desktop, vertical on mobile.

1. University invites students
2. Students complete their profile
3. Discover, join, and engage

---

## Footer

Contains:

- Logo
- Copyright

---

# Loading State

Static page — no loading state needed.

---

# Responsive Behaviour

Desktop: Full-width sections, horizontal feature grid

Tablet: 2-column feature grid

Mobile: Single column, stacked sections

---

# Accessibility

All text meets WCAG AA contrast.

CTA buttons are keyboard accessible.

Semantic HTML (header, main, section, footer).

---

# Components Required

- Button
- Card
- Navbar (public variant)

---

# Design Notes

Generous white space between sections (64–96px).

Hero section should feel spacious and inviting.

No heavy imagery — prefer abstract illustrations or clean icons.

Grayscale palette with subtle accent on CTA.

Smooth scroll between sections.
